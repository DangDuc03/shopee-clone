# 🛒 Shopee Clone with TypeScript

A full-featured e-commerce web application inspired by Shopee, built with **React**, **TypeScript**, **TailwindCSS**, and **Vite**. This project is structured with modern best practices, including linting, formatting, internationalization, SEO support, and component testing.

## 🚀 Features

### 🔐 Authentication
- Login, Register, Logout (using JWT)

### 🛍 Product Listing
- Pagination
- Sorting by attributes
- Advanced filtering
- Search products by keyword

### 📄 Product Detail Page
- Image gallery with slider & zoom effect
- Rich text product description (WYSIWYG HTML)
- Add to cart functionality

### 🛒 Shopping Cart
- Add, update, and remove products
- Checkout

### 👤 User Profile Management
- Update profile information
- Upload avatar
- Change password
- View order status

## 🛠 Technologies Used

- **React + TypeScript**
- **Vite** for fast build and dev server
- **TailwindCSS + HeadlessUI** for styling
- **React Query** for async state management
- **React Context** for global app state
- **React Router** for routing
- **React Hook Form** for form handling
- **React-i18next** for multilingual support
- **React Helmet** for SEO optimization
- **Storybook** for component modeling
- **Unit Testing** (structure ready)
- **ESLint + Prettier + EditorConfig** for code style and linting

## 🧰 Setup Instructions

### 1. Clone & Install
```bash
git clone https://github.com/your-username/shopee-clone.git
cd shopee-clone
yarn install
```

### 2. Start Development Server
yarn dev

### 3. Available Scripts
```bash
yarn lint          # Run ESLint
yarn lint:fix      # Fix ESLint errors
yarn prettier      # Check code formatting
yarn prettier:fix  # Fix code formatting
